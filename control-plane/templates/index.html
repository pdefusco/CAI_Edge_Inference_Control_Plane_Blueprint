{# The dashboard shell. Server-rendered content is deliberately almost nothing: identity of the deployment (env, registry, version) and the heartbeat interval, which the page needs in order to explain staleness to a human. Everything else arrives from the same JSON API the operator could curl, so the dashboard cannot show a state the API would not also report -- a dashboard with its own private view of the fleet is a dashboard that can lie.
